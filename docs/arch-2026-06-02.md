### F.3 Resilience risks that remain

1. **No global try/except in `run()` body.** If a non-CancelledError exception escapes the prelude or cycle loops, the exception will propagate out of `SprintScheduler.run()` to `run_sprint()` and then to `main()`. There is no top-level "soft-sprint result" fallback. Recommended: wrap the main run body in a top-level `try/except Exception` that returns a `SprintSchedulerResult` with `error=str(e)` filled in.

2. **`SprintTooShortError` (line 29 833) aborts immediately.** If a user passes `--duration 30`, the entire process exits. Could be a warning + minimum-clamp instead of `raise ValueError`.

3. **`asyncio.gather` is used in 20+ sites** with `return_exceptions=True` (per GHOST_INVARIANTS), but a few sites may be missing the `_check_gathered()` post-pass. Audit required.

4. **`add_argument` dead flags** (`--no-ghost`, `--no-stealth`) — misleading: user thinks they disabled a layer but they did not.
