## Key Technical Details

### Safari WebKit HTTP/2 Fingerprint
| Setting | Safari 18.0 | curl_cffi default |
|---------|-------------|-------------------|
| INITIAL_WINDOW_SIZE | 4,194,304 (4 MiB) | 65,535 (64 KiB) |
| MAX_HEADER_LIST_SIZE | 100,000 | 262,144 |
| PRIORITY frames | Disabled (RFC 9218) | Enabled |

### WINDOW_UPDATE Pattern
- Safari sends +1,048,304 byte increments (1 MiB - 216)
- Worker implemented: `_webkit_window_update_worker()`
- 80ms delay between requests (fire-and-forget)

### Feature Flag
```python
HLEDAC_H2_WEBKIT_PRESET = True  # Default ON
# Opt-out: HLEDAC_H2_WEBKIT_PRESET=0
```

## curl_cffi Integration Status

**curl_cffi 0.7.x:** `http2_settings` kwarg not available
- Preset constants loaded via Rust extension
- Session creation updated with `_session_kwargs` pattern
- Ready for curl_cffi >= 0.8.x: `http2_settings=http2_settings_dict`

**Future curl_cffi 0.8.x integration:**
```python
if _webkit_preset:
    _session_kwargs["http2_settings"] = {
        "initial_window_size": 4_194_304,
        "max_header_list_size": 100_000,
        "no_priority": True,
    }
```

## Known Limitations

1. **curl_cffi 0.7.x**: Raw HTTP/2 frame control (SETTINGS, WINDOW_UPDATE) not exposed
   - Workaround: Preset constants prepared for curl_cffi >= 0.8.x
   - Current behavior: Logging WINDOW_UPDATE intent only

2. **Rust extension requires build**: `uv run maturin develop` or `maturin build --features nw_framework`
