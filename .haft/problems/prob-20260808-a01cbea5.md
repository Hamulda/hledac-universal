# Haft Python detector fails on root-level __init__.py

## Signal

Haft code index degraded: Python detector returns "invalid module path ." error when project has __init__.py at root level. The detector expects canonical paths like "core/" or "src/" but finds "." (root). This causes module detection to fail while symbol indexing succeeds (1,599 files, 30,411 symbols indexed).

## Problem Type

diagnosis

## Problem Profile

thin

## P2W Readiness

p2w_candidate

## Acceptance

Code index coverage reports 'complete' or 'bounded' (not 'degraded'), and module detection works for root-level Python packages.
