- Three HTTP/3 strategies implemented: curl_cffi_opportunistic (default), NeqoRustlsTransportAdapter (M1 arm64 darwin), and AioquicTransportAdapter (fallback)
- LRU cache bounded by M1_BOUNDS.http3_lru_max (512 default) using OrderedDict for O(1) eviction
- Dark web TLDs (.onion, .i2p, .b32.i2p) never attempt HTTP/3 — always skipped
- Memory guard enforces 5.5 GiB RSS threshold with max 3 concurrent requests and 8s timeout
- Speculative Alt-Svc probe fires detached background HEAD requests (F265B)
- Strict exception handling: no bare except, always except Exception; errors return None never propagate
