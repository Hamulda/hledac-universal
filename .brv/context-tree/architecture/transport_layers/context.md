# Topic: transport_layers

## Overview
HTTP/3 lane implementation with two strategies: curl_cffi_opportunistic (default) and aioquic_stealth (opt-in). Features LRU caching, concurrency limits, memory guards, and speculative Alt-Svc probing.

## Key Concepts
- curl_cffi_opportunistic
- aioquic_stealth
- Alt-Svc cache
- memory guard
- speculative probe
- dark web bypass
