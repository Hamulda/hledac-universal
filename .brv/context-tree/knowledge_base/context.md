# Domain: knowledge_base

## Purpose
Contains meta-knowledge about the knowledge base itself - audits, maintenance, and gap analysis.

## Scope
Included in this domain:
- KB audits
- gap analysis
- stale content identification
- documentation maintenance

Excluded from this domain:
- Project source code documentation
- Architecture decisions

## Usage
